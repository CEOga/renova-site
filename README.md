# Renova

Адаптивный сайт по макетам Figma Renova: desktop, tablet и mobile. Макеты реализованы в одной странице с адаптивными контрольными точками.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из этой папки.

## Cloudflare Pages

Для этого статического проекта укажите папку `renova` как корневую, оставьте команду сборки пустой, а папку публикации задайте `.`. Подключите отдельный GitHub-репозиторий Renova, чтобы не смешивать его с проектом «Букет Молдавии».
